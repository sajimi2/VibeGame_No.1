# 统一像素规格 · 2026-09-23

**最新局部试验**：用户批准以人物现有37.5px/m为标尺做对照，入口 `play_pixel_density_lab.bat`。只校准驿站角落两墙、一箱与小块地面；F6前后切换、F7清晰缩放档位，正式F5和下方28px/m环境规则尚未整体迁移。两套当前并存的问题已确认，37.5仍是候选，须看实际对照后再定。细节与范围见 `assets/environment/painted/density_trial/README.md`。

用户要求统一低分辨率素材，但随后实测否定整屏640×360降采样：画面和场景小字受损。当前明确区分素材逻辑密度和最终显示分辨率；通过资产块面、色盘与采样统一，不靠整屏打码。固定正交视角、简单空间代理和人物管线继续沿用。

## 固定规格

| 对象 | 固定值 | 约束 |
| --- | --- | --- |
| 世界标准画布 | **1280×720** | 保留原显示细节，不安装整屏二次降采样 |
| 全屏显示 | 按窗口等比呈现 | 不把世界硬压成2×2块；像素密度约束施加于素材 |
| 界面设计画布 | **1280×720** | 像素插画背景/图标，清楚的中文字体；不把正文降到世界分辨率 |
| 环境制作密度 | **28逻辑像素/视平面米** | 以注册后的画稿宽高计算，四舍五入；禁止各件资产任意选密度 |
| 人物制作源 | **96×96、十二朝向** | 保存颜色/深度/握点；不改变世界模型、相机或显示比例，不二次损伤轮廓与深度 |
| 武器与特效 | 沿用现有制作源 | 保留已有像素表现，不对完整画面再次缩小 |

实现入口：scripts/presentation/pixel_standard.gd。F5不再装配WorldPixelGrid，旧环境F2采样也保持关闭；F2仅提示当前规格。交互物件名称投影到2D层，以17px清晰中文绘制，滚轮拉远不缩小字号。历史回归夹具保持旧行为。

## 制作尺寸不能只看PNG大小

AI原稿可以是大图，原稿尺寸不等于逻辑分辨率。必须同时登记主体裁切区、视平面宽度、脚点、碰撞/深度体积和逻辑采样尺寸。不允许一棵树保留高清碎叶、另一件道具只有几块粗像素。

本轮参考量级：原横墙137×72、原巨石48×40；新树三形约134×152、101×125、123×130，新版竖墙73×86。树体量大所以总像素更多，不能要求树和石墙拥有相同的PNG宽高。新竖墙以原粗像素横墙为母版；不采用此前偏写实的石墙/巨石草稿。

## 每次生图必须带上的美术要求

- 固定斜角正交相机：俯角35°、方位角25°，使用同批已验收资产作参考；左右墙向需要正确透视。
- 明确目标逻辑尺寸与28px/m密度：少量大色块、清楚的阶梯边缘、合并的亮暗面；不画细石纹、逐片树叶、照片颗粒或柔焦过渡。
- 树木与地表统一克制的橄榄绿/土褐色；光向一致。变化来自树冠轮廓、主干姿态和疏密，不能靠突然变黄、荧光绿或随意色相制造种类。
- 不在原稿中烘进另一套长投影；复用统一阴影。脚点接地处配少量腐殖土、苔藓、落叶过渡，避免整齐的贴纸边缘。
- UI用统一暗板岩、旧铁、织物的像素插画，纹饰避开文字/物品区域；正文优先可读，使用清晰CJK字体。
- 保存原稿、完整提示词、参考来源及配准清单。生图不能保证严格像素网格，生成后必须检查，不能只靠缩图滤镜把写实素材称为像素画。

## 验收

先把候选资产与现有横墙、巨石、玩家一起放进实际地图，在默认缩放1280×720与全屏观察，再检查放大后的轮廓、块面密度、色彩、落地接缝和重复感。单张原稿漂亮不代表能入场。

`tests/tactical/art_unity_test.gd` 验证无整屏降采样、树/墙逻辑采样、交互文字层级及缩放时字号稳定，并输出营地/树林/墙角/草地/背包实际截图；自动通过不代表风格和手感已获用户验收。
