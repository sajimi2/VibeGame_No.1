# 场景美术生产路线

2026-09-20 用户已确认：**固定正交视角完整绘画资产 + 隐藏简单空间代理**。以 `scenes/painted_courtyard.tscn` / `play_courtyard.bat` 为基准，后续默认沿用。不要恢复“给精细 3D 模型每个面单独生成贴图”的退役方案。

## 制作与发布

1. 先明确物件的脚点、占地、高度、门洞、承托/遮挡角色；交互性建筑可在 Blender 保存简单灰模，只验证游戏空间。不为瓦片/花叶/石缝建精细模型。
2. 以固定相机俯角 35°、方位角 25° 输出参考，直接生成完整单视角物件画稿。建筑按实际透视需要分出屋顶、墙身和内景；背景需真实 alpha，门洞不可画死，地面投影独立处理。
3. 保留原始 source、完整提示词、实际尺寸及配准。生图不保证严格相机/像素网格或尺寸，须检查轮廓、开口、光向和锚点；不能把生成结果当自动正确的几何。
4. 离线整理像素：小院实物按 alpha 裁切、约 28 源像素/视平面米缩图，保留 baked 记录；房屋各层对齐后按 320² 出运行图，registration 将设计坐标归一化。修改美术而非规格时不用重做人物。
5. 用 catalog/layout 实例化道具；盒/柱只做碰撞与近似深度。图像可以比碰撞更不规则，这是接受的设计，不要为完全吻合重建精模。
6. 在全屏 1280×720 逻辑画布查看静态/移动/前后绕行/进门/透视；确认后再加入地图。颜色/像素统一是艺术验收，自动通过不替代试玩。

## 空间、层次与遮挡

- 画稿 alpha 表示轮廓；简单体积表示碰撞/阻弹和近似深度，两者允许合理偏差。固定相机不可旋转，不为看不到的背面制作昂贵细节。
- 树使用树干脚点深度面，不能用树冠大盒子的前沿给树前玩家遮挡；一般物件使用近似盒深度。
- 花草与小装饰不参与碰撞或墙圆，不写角色遮挡深度，统一先于人物显示。蝴蝶/落叶不增加几何检测。
- 可进房屋的墙段独立分组，墙帽/窗框归本墙；全屋合成一个碰撞父节点会导致透视误联动。地板/桥/高台显式标记 support，不参与透视。
- 少量遮挡仅把被挡身体像素灰显；大片普通遮挡达到 90% 开墙圆，低于 80% 退出。中心全透、向外增加到 22% 残留；只有真正挡人的构件获准淡化。
- 屋顶室内整组保留 22% 再叠全透圆，室外仅圆；别隐藏整栋或挖掉承托地板。两圆尺寸和深度柔边、渲染顺序的契约见 `ARCHITECTURE.md`。

## 统一阴影与后续物件

所有新环境物件使用 `shadow_style.tres`，当前固定白天每米高度偏移 `(0.20,-0.54)`、绿灰色、22% 覆盖率、0.18m 柔边。profiles 仅填体量/高度/接触区，不填各自的方向或浓度。房屋使用轮廓凸包，树用树冠团块，不把整张正面画稿压扁斜投。

同件影形取并集不重复加深；不同件相交仍普通透明混合。人物实时投影同向同强度，但与环境叠片混色不是逐像素等价。地面纹理可透出；夜间灯光未实现，未来从共享样式扩展，不能逐个资产再硬编码。

新增 catalog 资产自动继承样式，无专属 profile 时按 depth_box 给默认影形。固定朝向的平移会同步锚点；轻微风摆调用 `set_visual_sway(Vector2)`，输入世界 XZ 米制偏移，限幅 0.12m，脚点/碰撞不动、上部画稿与影子跟随。默认无自动摇摆，不逐帧重建网格或纹理。任意旋转、坡面投影、复杂软体深度暂未支持。

## 显示精度与验证

新美术原始 1280×720 效果已确认，不额外默认降成 640×360。F2 保留对照，人物保持 96²/原倍率。全屏等比例铺满，非 16:9 允许必要黑边。

F2 使用世界锚定 + 整数 texelFetch 块内平均，不跨块模糊、不混合历史帧。不能回到归一化最近邻的块中心读取，它会在移动时跳选细砖缝。它只是颜色处理，未降低原始世界深度/光栅工作量，不称为性能优化。

运行 `scripts/check.ps1 -Suite art -Rendered`；实际 GPU 检查双屋隔离/通行、人物前后深度、地板保护、灰显、窗口全屏滚屏、影子/风摆/新资产默认。图片证据输出 work，不纳入版本管理。

## 保留的旧地图资产

荒堡、驿站、高度场仍实际使用 `environment_library`、`architecture_piece`、`terrain_builder`、`battle_prop`、旧 PNG/materials/prefabs 与 `tree_art`；保留用于玩法和空间回归，尚未整体换装。它们不再代表新增可见资产的生产方向。

维护原地图时保留木柱 0.03m 外包防共面、坡桥沿本地 -Z 上升、独立碰撞、support 标记；导航目前仍是单 XZ 单层，木桥基于实心坡道。`tools/build_environment_textures.gd` 仅显式维护旧 PNG，禁止对新画稿运行或覆盖手绘修改。

退役的逐面图片投影器、仓库贴面样板、旧小屋贴面入口与专用纹理已移出活跃树，需要历史时查 `ddb3b2c`，不要重新作为默认流程。
