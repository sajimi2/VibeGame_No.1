# 立体战术原型计划

现阶段：保留 scenes/tactical_height.tscn / play_height.bat 试验场；新增 scenes/battlefield.tscn / play_battlefield.bat 荒堡战场。旧 2D 四关保留在 Git 备份标签中，当前工作区仅维护 3D。最新实现和验证以 AI_SYNC.md 为准。

用户最新优先级：地图服务于战斗，玩家与敌人的攻击动作、流畅度优先于地图探索。

## 已确定方向
固定斜视角、正交投影、像素纸片外观配真实三维高度，镜头可跟随平移。人物十二朝向，身体/顶部粗粒度判定，不细分关节。
通行、视野、阻弹与破坏独立；墙不可穿，布帘遮视但可穿弹。高差通过实际视野和弹道获益。敌人失去目标后使用最后目击点，不读隐藏玩家新位置。
玩家与敌人被前景遮挡时有轮廓。保持小规模、有应对方式的敌人；不走刷怪堆量路线。

## 已完成
1. 坡道、高地、低洼、侧缘碰撞；下蹲、头顶阻挡、约一米跳跃与 Shift 疾跑。
2. 身体/顶部攻击、连续弹道、墙阻弹与布帘破损。
3. 近战守卫、弓手及追击、最后目击调查、地形路径和遮挡轮廓。
4. 十二朝向八相位步态、武器雏形、受击/音效、世界太阳投影。
5. 营地委托、拿信返回、两种装备、20 格背包、经验与独立保存。
6. 短关卡路线与两段遭遇：借矮墙接近路口守卫；用掩体和土坡应对高地弓手。保留绕行，无需清场。
7. 死亡重试、交付结算、首通/重复奖励提示；结果与背包交互。

## 接下来
先试玩战斗动作与节奏：攻击是否跟手、前摇是否清楚、挥出和命中是否对应、收招是否自然。根据实际交战调整断墙、巨石、坡道与敌人站位，减少无意义走路。
保持现有两种敌人，在其动作与应对方式稳定后再判断缺少什么战术角色。美术先统一可读性，再逐步提高局部质量，不以探索内容或地图数量作为本阶段进度指标。
不提前开展复杂多层导航、桥上桥下同时战斗、可转镜头或细分身体关节。

## 美术约定
- 配色与人物比例仍开放；参考图仅作质感、层次与细节参考，不照抄。
- 用户于 2026-09-18 要求人物向写实成人比例靠拢，保留十二朝向，玩家新增实际弯膝蹲起；持械使用共同握点。美术源文件、资料与当前实现见 ART_PIPELINE.md。
- 环境明确选择保留人物、树的现有细度，优先统一石墙、巨石，整幅世界画面不改成粗颗粒低分辨率。
- 用户已认可石墙/巨石风格。新增十二朝向疾跑与跳跃姿态、当前动画剪影投影；纸片改为竖直以修正贴墙深度。巨石移动凸包与精确阻弹面分开，保持外观与地图布局。
- 保留用户认可的像素树风格；地形不规则外形与统一像素密度，采用分段明暗，无全屏模糊降采样。
- 树、人物与建筑共用世界光照投影；昼夜参数接口保留，未启用自动时间循环。
- 当前为原创程序生成美术，不宣称完整正式素材包，也未下载商业参考素材。武器与纸片局部交叠留待后续打磨。
