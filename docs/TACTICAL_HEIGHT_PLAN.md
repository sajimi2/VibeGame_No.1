# 立体战术原型计划

现阶段：独立入口 scenes/tactical_height.tscn / play_height.bat，整理为“夺回密函”短关卡。原四关保留，不直接迁移。最新实现和验证以 AI_SYNC.md 为准。

## 已确定方向
固定斜视角、正交投影、像素纸片外观配真实三维高度，镜头可跟随平移。人物十二朝向，身体/顶部粗粒度判定，不细分关节。
通行、视野、阻弹与破坏独立；墙不可穿，布帘遮视但可穿弹。高差通过实际视野和弹道获益。敌人失去目标后使用最后目击点，不读隐藏玩家新位置。
玩家与敌人被前景遮挡时有轮廓。保持小规模、有应对方式的敌人；不走刷怪堆量路线。

## 已完成
1. 坡道、高地、低洼、侧缘碰撞；下蹲、头顶阻挡、短跳。
2. 身体/顶部攻击、连续弹道、墙阻弹与布帘破损。
3. 近战守卫、弓手及追击、最后目击调查、地形路径和遮挡轮廓。
4. 十二朝向八相位步态、武器雏形、受击/音效、世界太阳投影。
5. 营地委托、拿信返回、两种装备、20 格背包、经验与独立保存。
6. 短关卡路线与两段遭遇：借矮墙接近路口守卫；用掩体和土坡应对高地弓手。保留绕行，无需清场。
7. 死亡重试、交付结算、首通/重复奖励提示；结果与背包交互。

## 接下来
先由用户试玩本段关卡，集中打磨路线可读性、战斗节奏和影响判断的视觉穿插。保持两种敌人和一段闭环，体验稳定后再决定是否迁移其他区域或扩展装备。
不提前开展复杂多层导航、桥上桥下同时战斗、可转镜头、细分身体关节或更多大系统。

## 美术约定
- 配色与人物比例仍开放；参考图仅作质感、层次与细节参考，不照抄。
- 保留用户认可的像素树风格；地形不规则外形与统一像素密度，采用分段明暗，无全屏模糊降采样。
- 树、人物与建筑共用世界光照投影；昼夜参数接口保留，未启用自动时间循环。
- 当前为原创程序生成美术，不宣称完整正式素材包，也未下载商业参考素材。武器与纸片局部交叠留待后续打磨。
