# 固定斜视角战术原型

2026-09-16 用户批准开始。现有四关 v0.2-stage3 保留为独立可玩基线；新分支 tactical-height-prototype，新入口 scenes/tactical_height.tscn / play_height.bat。

## 已确定方向
固定正交斜视角，可跟随平移；像素纸片外观配真实三维高度。人物先八朝向、站立/下蹲，圆柱身体和顶部粗粒度判定；不拆关节、不先做趴下。树木房屋等静态素材按统一视角制作。
独立定义通行、视野、阻弹、破坏属性。墙不可穿，布可穿弹但遮视；高处通过实际角度和路径获益，不直接统一伤害加成。敌人丢失视野后依靠最后目击位置调查搜索，不读玩家实时坐标。
玩家被遮挡显示轮廓；敌人不因 UI 获得透视显示。暂不做桥上桥下同时战斗、复杂隧道及镜头旋转。

## 代码阶段
1. 空间试验场：真实坡道/高台/低洼，固定镜头，碰撞与高度。已实现。
2. 遮挡与姿态：玩家轮廓、下蹲碰撞、头顶阻挡检测。已实现基础版，整片屋顶淡出后续按场景需要做。
3. 攻击与弹道：身体/顶部粗判定、连续路径碰撞、石墙阻挡、布帘穿透和破损。待实现。
4. 感知追击：视线与视野、最后目击点、搜索、放弃、可通行高度路线。待实现。
5. 两种敌人：近战利用路线接近，弓箭手利用掩体射击/转移。待实现。
6. RPG 集成：复用背包/装备/经验/契约逻辑，适配空间相关接口；验证后逐关迁移。待实现。

## 美术阶段
统一镜头/像素密度/光照 → 地形样品 → 多朝向角色/下蹲 → 武器动作 → 环境纸片/遮挡 → 打击与声音反馈。
当前为原创代码生成的样品：八个朝向、两帧步行动作、简化下蹲、树木纸片、纹理方块地形。不是最终人物动画或完整素材包。

## 当前交付边界
新试验场尚无敌人、攻击、箭矢、布破坏、装备或存读档，不影响原四关。布帘现仅验证可步行穿过但遮挡显示的属性分离。WASD 移动、鼠标朝向、按住 C 下蹲、R 回起点、Esc 退出。
下一轮从阶段 3 开始，先验证弹道不能穿墙、穿布后仍能被后方墙阻挡，以及不同高度的攻击范围。

## 用户美术参考（2026-09-16）
参考图保存为 art_reference/user_style_reference.png，仅用于风格沟通，不作为自制素材或直接用于游戏场景。
- 参考图仅供探索像素质感、空间层次和环境细节，不照抄；配色未定，低饱和土褐/苔绿只是可选方向。
- 岩壁以不规则竖向岩块、裂隙和苔藓形成层次；自然高地不继续使用整齐砖墙外观。

- 树冠采用有体积层次的不规则轮廓，搭配石头、灌木、枯草等少量自然物。
- 人物比例未定，不要求更修长；优先保证动作和装备可辨认。固定斜视角、多朝向纸片方案保持。
- 本次仅记录美术目标，尚未替换试验场素材；参考图中的枪械和快捷栏不代表新增玩法需求。
