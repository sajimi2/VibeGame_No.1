## 已确定方向
固定斜视角、正交投影、像素纸片外观配真实三维高度，镜头可跟随平移。人物十二朝向，身体/顶部粗粒度判定，不细分关节。
通行、视野、阻弹与破坏独立；墙不可穿，布帘遮视但可穿弹。高差通过实际视野和弹道获益。敌人失去目标后使用最后目击点，不读隐藏玩家新位置。
玩家与敌人仅被前景遮挡的身体片段灰显。保持小规模、有应对方式的敌人；不走刷怪堆量路线。
