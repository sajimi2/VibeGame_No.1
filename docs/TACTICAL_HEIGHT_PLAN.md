## 已确定方向
固定斜视角，可跟随平移；正式选择正交；像素纸片外观配真实三维高度。人物现十二朝向、站立/下蹲，圆柱身体和顶部粗粒度判定；不拆关节、不先做趴下。树木房屋等静态素材按统一视角制作。
独立定义通行、视野、阻弹、破坏属性。墙不可穿，布可穿弹但遮视；高处通过实际角度和路径获益，不直接统一伤害加成。敌人丢失视野后依靠最后目击位置调查搜索，不读玩家实时坐标。
玩家被遮挡显示轮廓；敌人不因 UI 获得透视显示。暂不做桥上桥下同时战斗、复杂隧道及镜头旋转。

## 代码阶段
1. 空间试验场：真实坡道/高台/低洼，固定镜头，碰撞与高度。已实现。
2. 遮挡与姿态：玩家轮廓、下蹲碰撞、头顶阻挡检测。已实现基础版，整片屋顶淡出后续按场景需要做。
3. 攻击与弹道：身体/顶部粗判定、连续路径碰撞、石墙阻挡、布帘穿透和破损。训练靶基础版已实现，未接真实敌人。
4. 感知追击：视线与视野、最后目击点、搜索、放弃、可通行高度路线。待实现。
5. 两种敌人：近战利用路线接近，弓箭手利用掩体射击/转移。待实现。
6. RPG 集成：复用背包/装备/经验/契约逻辑，适配空间相关接口；验证后逐关迁移。待实现。

## 美术阶段
统一镜头/像素密度/光照 → 地形样品 → 多朝向角色/下蹲 → 武器动作 → 环境纸片/遮挡 → 打击与声音反馈。
当前为原创代码生成的样品：十二个朝向、四帧步行动作、简化下蹲、树木纸片、纹理方块地形。不是最终人物动画或完整素材包。
