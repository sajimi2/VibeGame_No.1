# 废弃哨站 v0.1 设计基线

## 用户已确认
俯视像素风；即时战斗；装备收集；升级成长。偏谨慎交战，强调看招、闪避、走位，少量敌人也有威胁。先用一把剑、一面盾、三种敌人验证手感，再扩展地图与装备。Codex 设计及审查，Harness 实现。

## 本轮设计默认值（可试调）
单人离线 Windows；640×360 逻辑画面、默认 1280×720 窗口；最近邻纹理。世界自由移动，不做格子回合。
WASD 移动、鼠标方向瞄准、左键轻击、右键按住格挡、Q 重击、Space 闪避、E 交互、I 背包、Esc 暂停。
菜单/背包打开后暂停世界输入和模拟；不在开局阶段制作键位重绑。

## 战斗规则
攻击依次进入 WINDUP / ACTIVE / RECOVERY。仅 ACTIVE 产生伤害；一个挥击可命中多个敌人，但对每个敌人最多一次。
轻/重攻击开始后不允许闪避或格挡取消；受击硬直和死亡可中断。出招方向在起手时锁定。
闪避消耗体力，穿过受击判定而不穿墙；仅中段无敌。输入零方向时沿当前朝向闪避。
格挡覆盖前方 120 度，按住时恢复体力暂停；体力不足被破防并进入硬直。背后攻击正常伤害。
敌人和玩家共用命中结算和行动协议，禁止 AI 自行修改玩家生命值。
原始伤害必须非负；物理伤害为 max(1, raw_damage - armor)，仅 raw_damage > 0 时应用。成功格挡生命伤害为零；破防本次承受正常伤害。
死亡只能触发一次；死后禁用行动、命中输出和受击，掉落/经验由遭遇系统消费一次死亡事件。

## 初始试调参数
玩家 HP 100，体力 100，移速 90 逻辑像素/秒。体力每秒恢复 24，消费后延迟 0.6 秒；攻击、闪避、格挡期间暂停恢复。
轻击：伤害 18、体力 16、前摇/有效/收招 0.16/0.10/0.28 秒。
重击：伤害 30、体力 30、前摇/有效/收招 0.38/0.12/0.45 秒。
闪避：体力 25、持续 0.32 秒、速度 240、无敌窗 [0.08, 0.22) 秒；不得超出墙体。
格挡每次消耗 event.stamina_damage；体力不足归零并硬直 0.6 秒。
普通受击硬直 0.18 秒；硬直时拒绝新动作。所有时间由物理 delta 累积，不依赖帧数。
参数进入 Resource 或配置，禁止散落在 UI、敌人脚本和动画回调中。

## 分阶段内容
第一关口：测试场、移动和碰撞。第二关口：剑盾玩家、一个近战盗匪、血条体力条、死亡重试。
然后加入弓箭手和野兽、背包装备与升级；最终串起村庄→林地→哨站→头目→回村领奖，目标单次 20～30 分钟，实际时长留待试玩验证。
装备槽：weapon/head/body/accessory；盾作为初始固定工具，v0.1 不单独掉落。背包 20 个位置、不堆叠。先做普通/优质两种稀有度与 12 个定义。
等级先限 5；从等级 L 升级需要 50*L 经验。每级 +1 未分配点，选择 +5 最大生命或 +5 最大体力，增加上限不治疗。满级后经验归零、下一等级需求为零，后续经验忽略。
首次死亡返回村庄、HP/体力恢复满值，保留装备与经验、重置当前遭遇；以后是否添加死亡惩罚交给用户决定。
暂不包含联网、随机世界、制作、饥饿伤势、复杂剧情、技能树、商店经济和最终美术。

## 像素风实现
T01～T03 使用明确标记的几何/像素占位图，优先出招可读性。T06 换统一像素资产；世界元素遵循 16/32 像素基准和受限色板。记录素材来源及授权，不挪用 Stoneshard 资源。
