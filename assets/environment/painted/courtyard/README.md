# 林间小院：固定单视角绘画资产实验

2026-09-20。用户允许画稿与隐藏盒/柱碰撞近似吻合；用户已确认这条美术路线，后续默认沿用；当前仍是独立可走动场景，尚未把正式战场全部换装。

## 查看

运行工程根目录 `play_courtyard.bat`，或 F6 运行 `scenes/painted_courtyard.tscn`。双屋实例隔离回归夹具 `tests/fixtures/painted_cottage_scene.tscn` 仍保留。

- WASD 移动，空格跳跃，C 下蹲，F11 全屏，F2 环境粗/细对照。用户确认本实验默认原始 1280×720，不再默认开启环境 2×2 降采样；角色不变。
- V 切换绘画与简单空间体积；小屋显示原空间几何代理，院中物件显示半透明碰撞体积。
- F3 叠加物件碰撞体积；F4 开关蝴蝶/落叶；M 切换全院固定取景与跟随。只平移相机，不改变原角度、角色显示倍率。
- 1 院门、2 室内、3 树井旁、4 推车旁，R 重开。没有敌人、任务或真实存档写入。

## 资产与制作

通过内置 **imagegen** 工具直接生成十张可入场景的单视角原稿，以前轮完整小屋图为风格参考，没有另做概念图再建精细模型。`prompts.json` 保存每件资产实际使用的完整提示词和参考路径。

| 内容 | 实例 | 空间表示 |
| --- | --- | --- |
| 不规则橡树 | 3 | 树干圆柱碰撞；树冠独立近似深度范围 |
| 错落石墙 | 4 | 规则长方体碰撞；顶部与石缝由画稿表现 |
| 苔石 | 4 | 圆柱碰撞 |
| 推车、打开的宝箱 | 各 1 | 长方体碰撞 |
| 水井、水桶、树桩 | 各 1 | 圆柱碰撞 |
| 花草 | 34 簇 | 纯装饰，无碰撞 |
| 蝴蝶、落叶 | 4 / 21 | 简单动态色片，无碰撞 |
| 草地 | 1 张重复纹理 | 草的细节无碰撞；地面的承托碰撞单独存在 |

`source/` 保留未经覆盖的生成原稿，以 `.gdignore` 排除运行时导入。`catalog.json` 声明显示宽度、脚点锚点、碰撞尺寸和独立深度范围；`layout.json` 只声明实例摆放。需要新物件时沿用同一模块，不复制控制器。

开发期运行 `tools/bake_painted_courtyard.gd`：按 alpha 裁出有效区域，再按 **每视平面米约 28 个源像素**统一降采样，写入 `textures/`；草地单独为 192²。`baked.json` 记录真实原图尺寸、裁切和最终尺寸，不能假设生成尺寸等于请求值。原稿约 1254²，横向墙图为 1536×1024。像素密度是这一实验的可调基准；缩放实例会略改变密度，不宣称所有物件绝对一致。角色仍使用已确认的 96² 资产，未重烘焙。

## 空间与维护约定

`illustrated_prop` 负责朝向固定相机的绘画平面、独立简单碰撞与遮挡参数绑定。画稿 alpha 决定可见轮廓；普通实物使用近似深度盒，超出盒范围的边缘使用脚点平面近似。树木改用经过树干锚点的竖直深度面：不得恢复用树冠宽盒的最前面代表整棵树，否则人物站在树干前也会误灰。花草改用 `ground_decoration`，仅借地表深度遮住穿建筑的部分，不写环境遮挡深度，先于人物绘制；不参与墙圆和灰显判定。

普通实物遮挡沿用现有灰色被挡片段与墙圆：隐藏参考网格参与原遮挡采样，注册完成后复制最终材质的透视参数。实物绘画走 alpha 裁切不透明通道，先进入环境像素处理，再与角色进行深度比较。纯花草走不写深度的透明通道（优先级 -110，人物之前），因此 F2 不再额外粗化花草。小屋仍沿用原屋顶/墙控制器，内景已补画。

阴影使用**独立体量轮廓 + 唯一白天样式**。`shadow_style.tres` 统一世界光向 `(0.20,-0.54)` / 米高度、22% 覆盖率、绿灰色、0.18m 柔边、28 像素/米和 0.12m 晃动上限。`shadow_profiles.json` 只描述团块位置、半径、高度、接触区或凸包点，不允许每种物体自定透明度与方向。树、井、车、墙和房屋共用 `illustration_shadow`；同件物体内所有部分取并集，接触影不额外加深。独立物件相交时仍是普通透明混合，不是全场景阴影并集。

房屋在新小院调用 `painted_cottage.setup(cottage)` 接管影子：屋檐/屋脊/墙脚投影形成柔边凸包，原实时代理退出投影与颜色层，几何采样和碰撞保留。V 对比恢复旧代理并关闭新影形；双屋回归也使用同一默认样式。人物保持实时姿态投影，小院通过同一样式对齐太阳方向与 `shadow_opacity`，接触影也降至相同上限；实时光照与透明叠片不是完全相同的合成方式，不能承诺每个像素颜色一样。画稿本身画好的明暗不重绘。

新实物沿用 `illustrated_prop.setup`，自动接入共享样式；未添加专属轮廓时由 `depth_box` 生成默认影形，再按需补 profile 即可。平地平移会通过变换通知同步 `prop_origin` 与阴影锚点，静态物件无逐帧同步循环。`set_visual_sway(Vector2)` 接收世界 XZ 小偏移（米）：画稿由脚点向顶部渐增偏移，影子上部跟随、接触区和碰撞不动；输入限幅，地面承载面预留边界，不逐帧生成图片或网格。返回零恢复静态图，调用方拥有动画时钟，默认未开启自动风摆。画稿只加少量纵向分段用于弯动，不生成物件细节模型。

阴影不写深度，优先级 -120，以世界网格保持像素边缘。范围仍是固定镜头/资产朝向、平地及小幅形变，不支持任意旋转、倾斜接收面或复杂非刚性深度；不等于已实现可移动交互道具。画稿突起与空隙的深度仍为近似，物理体积可站立不意味着设计为可攀爬。夜间灯光尚未实现；以后可替换共享样式，不为每种新物件另写光向和浓度。
