# 林路统一像素资产

标准见 `docs/PIXEL_ART_STANDARD.md`：标准画面1280×720，无整屏降采样；环境28逻辑像素/视平面米；风格向原粗横墙和巨石统一。

- `source/`：内置 image_gen 生成的完整原稿，保留原始透明度，不做外部抠图。三树形、草地、竖墙、树根碎叶。
- `prompts/`：逐件完整生成提示词。tree_b/tree_c以tree_a作色彩/风格母版；wall_z以旧 `courtyard/textures/wall.png` 137×72原图为参考生成垂直方向。没有接入偏写实的墙/石草稿。
- 2026-09-23色差反馈修正：当前竖墙用 `source/wall_z_v4.png`，完整提示词 `prompts/wall_z_v4.txt`。内置image_gen以旧竖墙为编辑对象、横墙为石色/石块/苔藓参考重新生成，弱化亮米色与黄绿色；保留旧稿便于对照，不改变墙体碰撞。
- `catalog.json`：真实alpha主体区域、尺寸、脚点、碰撞、深度和像素密度。保留旧残屋等仍使用的条目；旧树条目仅为来源兼容，当前林路不使用。
- `tools/register_unified_woodland.gd`：只读取原图并登记区域/尺寸，不改写图片。
- 运行时由 `illustrated_prop.gd` 按世界尺寸与28px/m离散采样，完整世界不再二次缩小；原图大尺寸不代表运行时高清呈现。

原横墙/巨石继续引用原小院低分辨率纹理。树形按固定种子与道路/交互点避让摆放；脚底薄层、碎叶和统一树影负责过渡。草地用同色原稿的多区块偏移混合与低频色斑削弱重复，保留旧道路与碰撞。

本轮生成方式：内置 `image_gen`，未使用CLI/API回退。美术是否充分自然仍须在实际游戏中验收，源图数量有限，不宣称消除全部重复感。
