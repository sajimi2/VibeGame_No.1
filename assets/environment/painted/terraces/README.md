# 分层地形最小美术套件

对应小院外围 `terrace_layout.gd` 的 4m 粗格和 0.5m 高度步长。人物仍自由移动。

- `source/cliff_master.png`：内置 image_gen 生成的 1536×1024 原稿，未覆盖；完整提示词见 `prompt.txt`。
- `textures/cliff.png`：显式运行 `tools/bake_terrace_art.gd` 输出的 224×112 最近邻整理图。
- 顶面复用已验收的小院草地/泥土纹理。崖壁共享一个带草沿的母版；不为单块、1×2 或 L 形分别生图。
- 侧壁横向每 8m 采样一次母版并镜像往返。世界横坐标保证同方向直段连续；UV2.x 存距本段崖顶的真实米数，前 0.18m 对应图的上部 12% 草根带。
- 顶面四边标志来自同一外露边列表；内部同高边不生成墙和草沿。凸角、凹角由真实边界相交组成，坑壁由周围较高格生成。几何接口严格闭合，画稿负责石缝与草根细节。
- 左右壁共享绘画笔触，按小院公共太阳方向分别明暗处理。没有使用图片镜像来翻转光照；水平镜像仅用于母版端点连续采样。
- V 灰模切换、F3 粗格参考只改显示；碰撞与导航始终来自同一布局。

复现：Godot `--headless --path . --script res://tools/bake_terrace_art.gd`，然后编辑器导入。运行 `terrace_ground_test.gd` 保存真实场景截图到 `work/terraces/`。原稿不参与资源导入，由 `source/.gdignore` 隔离。

当前是共享绘画母版与简单地形网格组成的第一套拼接美术，尚未增加专门的岩壁变体或不规则外伸崖角；接缝与风格需实际试玩验收。
