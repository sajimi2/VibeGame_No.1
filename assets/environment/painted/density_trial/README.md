# 局部像素密度对照（候选，不是全图标准）

启动根目录 `play_pixel_density_lab.bat`，复用当前驿站同一角落。F6切原版/校准，F7在原视野、每逻辑像素2点、3点间带阻尼切换；走动与E开箱可用。测试进度隔离，退出不写真实存档。正式F5没有接入。

## 发布与来源

`tools/bake_density_sample.gd`从已保存原稿发布6张独立运行图；没有生新图、覆盖旧纹理或升采样旧小图。发布后须执行Godot导入。原稿/原有生成提示词在各自来源目录。

- 横墙：`courtyard/source/wall.png`，沿用 `courtyard/baked.json` 的主体裁切。针对场景中0.8倍墙的实际3.92米宽，发布147×77。
- 竖墙：`woodpath/unified/source/wall_z_v4.png`，沿用catalog主体区域，发布98×116（具体尺寸以manifest为准）。
- 宝箱：`woodpath/source/chest_motion.png`；2103源宽不能整除4，各帧边界分别取整，发布四张53×75。试过面积混合后扣环灰化，当前取硬边样本；这是密度样本，不能代替逐帧像素美术修整。

`manifest.json`记录源区域尺寸、运行尺寸与画稿世界尺寸。密度使用人物既有的37.5像素/视平面米。小图每像素实际占1/37.5米，不靠截图后处理统一；宽高取整造成画稿尺寸小于1%的调整，物理体积与原脚点配准约定保留。

## 接入边界

`tools/pixel_density_lab.gd`仅替换驿站东南角两面墙、一只货箱和X[59,70]/Z[-10,1]地面采样。草地把世界点投影到固定镜头的right/up平面，量化后反解XZ；使用世界锚点，不随镜头平移重选格子。它是平地、固定镜头实验，不能直接宣称支持任意坡地与旋转相机。

F7的2/3点按1280×720设计画布计算；非整数倍全屏显示仍可能出现像素宽窄分配。滚轮仍保留连续缩放，若随意停在非整数档位就不保证整数屏幕像素。人物源/动画/握点未改，UI名称仍独立清晰绘制。

自动验证见 `tests/tactical/pixel_density_trial_test.gd`；同机位前后、默认/2点/3点、开箱和移动截图输出在 `work/pixel_density_trial/`。统一了采样尺寸不等于已统一所有材质风格；井、房屋、远墙和树未迁移，不能拿实验角落推广成整图已完成。
