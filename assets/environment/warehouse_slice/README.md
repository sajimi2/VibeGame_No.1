# 仓库与门前小院 · 生成美术样板

已验收小屋的回退提交为 `b9301bf`（已推送）。本资产把同一表面投影流程迁移到 12m 宽、带侧门/敞开装卸口/1.8m 高台的现有仓库，供用户测试整体风格和战斗可读性。

## 运行

打开 `scenes/warehouse_art_slice.tscn` 按 F6，或从项目根目录运行 `play_warehouse_art.bat`。以全屏查看为主：F11 切换全屏；V 对比新旧环境；P 切换战斗/勘察；勘察时 1 到桥前、2 到仓库内；F2 对比环境精度；R 重开。出生点是桥前营地，可恢复生命。I 可切现有三种近战武器。

两名守卫和一名弓手复用现有演员、强化参数、导航、命中和死亡表现。无任务、奖励或真实存档写入。勘察冻结敌人行动并取消待发攻击，保留血量与位置；已发出的箭仍遵循原弹道，玩家勘察期间免伤。

## 制作源与复用边界

| 文件 | 职责 |
| --- | --- |
| `scenes/waystation_blockout.tscn` | 本样板既有简模/碰撞的唯一来源；继承场景复用其全部布局，不另复制一份 Blender 地图造成双源漂移 |
| `bindings.json` | 资产局部原点、样板地表区域、目标网格到投影配置的对应、旧装饰隐藏列表及箱桶摆放 |
| `projections/*.tres` | 图片、纹素密度、UV 原点/投影轴、外表面选择、重复和颜色校准；可以在 Godot 检查器修改 |
| `textures/*.png` | 内置 imagegen 的六张原始输出：墙、瓦、石、板、草、土；保留原图，不用概念截图替代深度 |
| `prompts.json`、`roof_prompt.txt` | 实际生图提示词；参考 `experiments/cottage/art_proposal_v1.png` 的风格。屋面单独针对仓库尺寸制作，避免把小屋瓦片直接放大 |
| `props/{crate,barrel}.tscn` | 简单可复用货箱/桶与显式碰撞；箱体沿用原构件，桶仅粗圆柱与铁箍，表面细节来自图片 |

`surface_projection.gd` 是小屋与仓库共用的投影器，只生成 UV 和材质，不生成导航/碰撞/状态机。原型小屋原有写死映射已移入它自己的 `projections/`，原 Blender 文件和 GLB 没有重建。

`warehouse_art_layer.gd` 在关卡环境装配阶段读取配置，给既有网格赋予新 UV 和独立材质，在墙圆注册前完成。仓库屋顶已经就绪，因此把图片参数交给其现有材质，透视状态仍由原控制器持有。正面仍是原装卸开口及两段低墙，不改成小屋的实体前墙。

大地面的新草/土材质只在配置区域内生效，边缘 3m 渐回原地表；土路按原网格边缘逐步露草。重复 UV 不能用于边缘判定，因此投影器将原 UV 保存在顶点 COLOR.rg，UV2.x 保存外表面掩码。这一约定适用于当前无顶点色美术的静态简模。

V 保持投影网格、碰撞和注册状态，只切图片采样与旧细节显示。小型新增箱桶在两种模式均保留实体并切换表面风格；原墙面的密集装饰在新模式隐藏，薄木包边在新模式显示且随父墙透视。地板/高台/桥的 `support` 标记保持。

## 基准和限制

- 相机仍为 (-35°,25°,0°) 正交，视野 17/1.2；人物维持 96² 和已确认显示尺寸。
- 大部分生成贴图约每米 30 个逻辑纹素，环境保留 F2 640×360 对比。原始 PNG 较大，着色器按配置网格取色；逻辑纹素数不等于显存占用。
- 生成图片可能有接缝或局部固有阴影，仍须看实际拼接和走动；精细轮廓不能靠平面贴图自动产生。当前箱桶和木端柱只用少量辅助几何。
- 当前只验证这块样板与小屋，不代表其他建筑任意缩放即可自动获得正确门窗布局。

## 验证

`warehouse_art_slice_test.gd` 验证既有碰撞未移动、实际图片/比较开关、真实上下桥/穿门、地板保护、室内与背墙透视、飞行箭撞墙和守卫真扣血，截图 `work/warehouse/`。

`warehouse_motion_test.gd` 在实际窗口/全屏下横向、纵向、斜向平移相机并抵消位移比较像素，阈值沿用低于 1%；同时记录冻结演员后的静态渲染帧间隔、绘制调用与显存，输出 `work/warehouse/render_metrics.json`。该观测不代表实际战斗的最低帧率；玩法流畅度仍由试玩验收。
