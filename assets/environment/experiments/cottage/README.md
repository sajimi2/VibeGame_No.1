# 小屋实验 · 生成表面美术接入

目标：验证简单 Blender 几何 + 生成图片的环境制作路线。当前生成贴图已进入游戏材质，简模仍是深度、碰撞和透视的依据；实验场放置两份相同预制件验证复用。正式地图未替换，画面风格仍由用户试玩验收。

## 入口与源

- `tools/cottage_art_lab.tscn`：Godot F6，真实玩家移动、碰撞、阻弹与两层透视；无敌人、任务、存档。
- `source/cottage.blend`：可人工编辑的简模源，子目录 `.gdignore` 防止 Godot 隐式调用 Blender。
- `cottage_shell.glb`：从上述已保存源导出的网格。墙宽 5m、深 6m、高 2.8m，屋脊高 4.1m，门洞宽 1.5m、高 2.2m。
- `cottage.tscn` / `cottage.gd`：实验预制件，按 Blender 物件名装配墙体碰撞、独立屋顶和受保护地板。GLB 为显示和碰撞共同来源，不另维护一份尺寸。
- `gray_reference.png`：首次生图使用的 Godot 1280×720 灰模参考，包含现有玩家作比例参照。相机角度/倍率同正式游戏，取景中心只做平移以容纳完整小屋。后续测试截图只写 `work/cottage/`，不覆盖生图输入。
- `art_prompt_v1.txt`：内置 imagegen 的完整提示词；第二张输入为用户提供的中世纪像素场景，仅作风格参考。
- `art_proposal_v1.png`：内置 imagegen 生成的首版红瓦/木骨灰泥小屋提案，原输出保留。生成器对轮廓、人物与背景并非逐像素锁定；这张图只用于外观/风格参考，运行材质使用下述独立平面图，不能把提案当作深度图或碰撞依据。
- `textures/front.png`、`side.png`、`roof.png`：内置 imagegen 根据上述提案分别制作的平面立面/屋面原图，直接保存工具输出；不是从概念图机械裁切。完整提示词见 `texture_prompts_v2.txt`。封闭侧窗只在外侧显示，室内复用现有灰泥、木地板和箱子材质。

## 试玩与装配

- 打开 `tools/cottage_art_lab.tscn`，F6 运行。V 切灰模/美术；1、2 到两栋小屋门前；F2 对比环境精度；F11 全屏；WASD 移动。
- 门左、门右、门楣与正面三角山墙归到一个 `FrontWall` 静态实体，共用一张完整立面图与同一透视状态。门洞所需的原始几何/碰撞仍分块，透视不再逐小板单独开启；侧墙、后墙、屋顶独立。
- `cottage.gd` 按简模局部位置给顶点生成 UV，UV2.x 标明外表面；`art_surface.gdshaderinc` 只替换颜色，原表面仍写真实深度、接收光照并保留原有阴影代理。前墙/侧墙/屋面取色网格分别为 150×123、180×84、201×98，人物继续使用原 96×96 图集。
- 贴图和 UV 固定在资产自身，不随复制位置滑动。两个实例独立持有材质与透视状态；屋顶通过可选 `surface_material` 输入图片，原控制器仍管理室内淡化/局部透视。
- V 只切颜色，墙体控制器同步显示副本的对比参数；不重建碰撞、遮挡注册或改变角色精度。

## 日常导出

```powershell
& 'D:\blender\blender4.2\blender.exe' --background --factory-startup --disable-autoexec --python-exit-code 1 --python tools/blender/cottage_experiment.py
```

默认只读保存的 `.blend` 并导出 GLB，不重建或保存模型。`--init` 仅用于首次生成简模，源存在时明确报错，防止覆盖人工修改。保留 `Roof*`（不添加行走碰撞）、`Support*`（排除墙圆）及前墙各部分的物件名称约定；`GableBack` 随后墙，前墙四块共组，其他网格各自成为静态实体。

## 当前约束

相机为正交，旋转 (-35°,25°,0°)，size=17/1.2；人物继续使用 96×96 烘焙角色。屋顶控制器仍使用现有薄盒局部包围盒判定，因此本阶段保留两片长方体坡屋面。外地面比室内地板低 2cm，避开共面深度争抢。生成美术只允许丰富表面，不擅改屋顶轮廓、门洞和地形。

当前采用平面立面贴在简模表面的方案，不是整张概念图的相机投影，也没有从图片恢复三维深度。轮廓仍来自现有简单模型，图片不能提供真实突出的屋檐雕饰；复杂轮廓以后需要少量辅助几何或独立部件。UV 尺寸按本屋约定编排，修改门洞/墙高时需同步映射和美术。生成图带局部明暗，后续光照风格扩展仍需检查明暗重复。
