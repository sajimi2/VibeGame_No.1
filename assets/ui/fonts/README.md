# 像素中文字体

使用 [Fusion Pixel Font](https://github.com/TakWolf/fusion-pixel-font) 的 `fusion-pixel-12px-monospaced-zh_hans.ttf`，来自官方 [2026.09.01 发布](https://github.com/TakWolf/fusion-pixel-font/releases/tag/2026.09.01)。原许可 `OFL.txt` 与上游素材许可 `LICENSES/` 一并保留；字体未修改。

`scripts/ui/pixel_style.gd` 统一关闭抗锯齿和子像素定位，UI最近邻采样；边框是整数像素九宫格，装备人形是整数矩形轮廓。全屏时仍按1280×720设计坐标布局。
