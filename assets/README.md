# 原创像素与音频雏形

本目录及 scripts/ui 中的第三阶段表现代码由 Codex 为 OutpostRPG 原创制作，无外部素材、付费包或第三方音频依赖。

- pixel/pixel_assets.gd：16×18 像素人物底板和角色色板。点阵字符为可编辑源文件，运行时转为最近邻像素贴图。
- scripts/ui/pixel_actor.gd：分层身体/腿部/武器、步态、挥砍、闪白、格挡火花、伤害数字和死亡表现。
- scripts/ui/pixel_world.gd：32 像素地面基准，建筑/树林/水池/石墙按原碰撞矩形绘制。
- scripts/ui/sfx_player.gd：原创 PCM 音效、短调式音乐循环与环境声，运行时合成；不需下载资源。
- Esc 可调整总音量、音乐、音效和受击震屏。本版选项在运行期间保留；声音是可玩的合成雏形，后续可替换成采样素材。

可复用的点阵源文件与程序绘图属于原生可编辑美术实现。当前不是完整的外部 PNG 图集或录音资产库。
