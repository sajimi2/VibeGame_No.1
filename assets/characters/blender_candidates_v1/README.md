# 四种敌人的 Blender 模型候选

这批文件用于选择造型，尚未制作骨骼、蒙皮权重、动作、Godot 烘焙或游戏接入。预览 PNG 是 Blender 的实体模型渲染，不是最终像素效果。

## 如何查看

在 Blender 4.2 或兼容版本中使用「文件 → 打开」：

- `enemy_lineup.blend`：四角色同一比例总览，左起哥布林、骷髅兵、史莱姆、石头人。
- `goblin.blend`：已确认概念的拾荒哥布林，尖耳长鼻、锈红短衣、腰包与独立短矛。
- `skeleton.blend`：镂空肋骨与头骨眼眶，残旧肩甲、短剑和小圆盾。
- `slime.blend`：低矮不对称胶团，胶质色块与眼部。当前材质不依赖透明折射，方便后续评估像素烘焙。
- `golem.blend`：宽肩石段、厚重手脚、石面苔藓与暗金色眼睛/胸口核心。

中键拖动旋转，滚轮缩放；小键盘 1 / 3 / 7 看正面、侧面和顶面。右上 Outliner 的 `MODEL_*` 集合是角色，`STUDIO__not_part_of_model` 是摄影灯、相机和地面。身体、服饰和武器保留可编辑部件；检查独立部件时可选中后按小键盘小数点聚焦。

`*_front.png`、`*_back.png`、`*_preview.png` 提供三角度检查；`lineup.png` 是同尺度对照。单个角色的检查图各自取景放大，不能用它们比较实际身高。`goblin_concept_reference.png` 保留此前确认的概念参考；其右下角像素图仍只是意向，并非这些模型的实际烘焙结果。

## 制作边界

- 使用米为单位，Z 向上、角色面向 -Y，最低点对齐地面。进入 Godot 时由导入器转换坐标，不能直接照搬 Blender 的轴。
- 使用实体网格与材质色块，没有外部贴图依赖。每个独立文件只显示自身模型，摄影环境单独分组。
- 哥布林皮肤经融合塑形；骷髅与石头人保留分段结构；史莱姆是连续主体。这些是可编辑造型初稿，尚非最终变形拓扑或已验证动画资产。
- 选定候选后再整理拓扑、制作骨骼/权重和少量动作，测试十二朝向烘焙与实际游戏表现，不自动将四者加入敌人库。
- 本目录的 `.gdignore` 防止 Godot 自动导入 `.blend` 或要求本机 Blender 路径。当前 `art_preview` 和 F5 不会加载这些候选。

## 复现与验证

初稿生成入口是 `tools/blender/create_enemy_candidates.py`；使用本机 Blender 后台执行，传 `-- --out <新目录>`。可加 `--only goblin` 等参数只制作一个候选。若目录已有同名 `.blend`，工具拒绝覆盖，防止抹掉人工修改；后续精修以保存的 `.blend` 为准。

`model_report.json` 记录各模型网格数量、三角面数量和含装备包围盒；哥布林含短矛的高度不能当作身体身高。`validation.json` 记录独立进程重新打开文件后的结果。验证入口为 `tools/blender/inspect_enemy_candidates.py -- --folder <本目录>`。
